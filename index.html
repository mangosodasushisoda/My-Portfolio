Scratch作品

ニワトリクリッカー — ニワトリと卵をテーマにしたゲームです。下の埋め込みからそのまま遊べます（Scratch 公式サイトの埋め込みです）。

Scratch で別タブを開く

使い方

  • ニワトリをクリックまたはタップすると、卵を産んでくれます。
  • 矢印ボタンを押すと下に行けます。
  • ここでは卵が流れて売られます。
  • 卵をクリックかタップをすることで磨かれて品質がアップします。
  • 最大で 10 回磨くことができます。
  • モニターには、最後に売られた品質と値段が書かれています。
  • 黄色のダイヤマークは品質を表しています。
  • 卵の色の P で買い物をします。
  • 品質が高いほど早く売れます。
  • 矢印の隣にあるショップマークを押すと、ショップに行けます。
  • 矢印で買うものを選ぶことができます。
  • 人のマークのボタンを押すと、ゲーム画面へ移動できます。
  • このゲームは、黒い卵にニワトリが触れると、終了です。
  • やめるボタンを押すことでも終了できます。

メモとクレジット

  • 音楽: 魔王魂
  • 効果音: 効果音ラボ

AIと一緒に開発しました

ひよりAIシステム（Hiyori AI System）

「2日間で構築した、自律的に思考し語りかける対話エージェント。」LFMによる高速思考と、VTube Studio連携による生命感のある表現を両立。

実行用コードは my_aituber/ フォルダにあります。ソース一式は ZIP で入手できます（手順は README）。

ZIP をダウンロード README を開く 配布の注意

vts_token.txt について: VTube Studio のプラグイン認証トークンが入るため、公開用 ZIP には含めていません。展開後は初回に python main.py を実行し、VTS 側の許可ダイアログで各自がトークンを発行してください。

フォルダ構成（配布用の目安）

バージョン管理や ZIP では .venv は含めず、requirements.txt から再インストールしてもらいます。ZIP の再生成は PF ルートで ./package-my_aituber.sh です。

my_aituber/   （ダウンロード ZIP に含まれるもの）
├── main.py
├── requirements.txt
└── README.md

ローカル開発・実行時のみ（ZIP には含めない・自動生成もあり）
├── .venv/              … 仮想環境（配布禁止）
├── vts_token.txt       … VTS 認証（秘密情報のため配布しない）
├── chat_history.db     … 会話ログ（実行時に作成）
└── temp.wav            … 音声一時ファイル

実行時に自動生成: chat_history.db（会話ログ）、temp.wav（音声一時ファイル）。

main.py がしていること

LLMOpenAI 互換 HTTP API（既定 http://localhost:1235/v1/chat/completions）。ポートは LM Studio 側に合わせて LM_URL を編集。
VOICEVOXhttp://localhost:50021 で音声合成し、macOS では afplay で再生（他 OS は README 参照）。
VTube Studiopyvts で接続・認証（vts_token.txt）。テキストから表情ホットキー HAPPY / SAD / SURPRISE を送信。
記憶SQLite chat_history.db に直近の発話を保存し、プロンプトに連結。
独り言stdin に入力がない間は約 5 秒で自動プロンプトを投入し、自律発話するループ。

配布について

  • サイトの 「ZIP をダウンロード」は package-my_aituber.sh で作った ソースのみです（main.py・requirements.txt・README.md）。
  • .venv は OS 依存のため含みません。
  • vts_token.txt は認証情報が入るため ZIP に含めません。自分用バックアップとしてローカルにだけ置くのが安全です。

使い方（概要）

  1. LM Studio（または互換 API）・VOICEVOX・VTube Studio を起動する。
  2. my_aituber で仮想環境を作り pip install -r requirements.txt する。
  3. python main.py を実行し、コンソールから入力。終了は exit または さよなら。

ポート番号・Windows での音声再生・VTS ホットキー名のカスタムは main.py / README に記載しています。

pRomptAI MVP

「自然言語を、即座に動的な実行環境へ。」ローカルLLMと実行エンジンを融合したインターフェース。

pRomptAI を開く エディタへ直行

LM Studio の設定

  1. LM Studio を起動し、使うチャット用モデルをダウンロードして読み込む（Load して推論可能な状態にする）。
  2. 左の Developer または Local Server（バージョンにより表記が異なります）を開き、Start Server でローカル API サーバーを起動する。
  3. API のベース URL はエディタが http://localhost:1234/v1/chat/completions を想定しているため、LM Studio 側の待ち受けポートを 1234 にする（未使用の場合は Settings でポートを 1234 に合わせる、または後述のとおりコード側の URL を変更する）。
  4. エンドポイント形式は OpenAI 互換の POST /v1/chat/completions である必要があります（LM Studio のローカルサーバー既定のまま利用で問題ないことが多いです）。

注意点

  • LM Studio のローカルサーバーが起動していないと、エディタから AI へ fetch しても応答しません。先に LM Studio 側でサーバーを立ち上げてください。
  • ポートを 1234 以外にした場合は、pRonptAI/edit/js/ai.js の url または pRonptAI/edit2/js/constants.js の endpoint を、実際のベース URL（例: http://localhost:ポート/v1/chat/completions）に書き換えてください。
  • ポートフォリオやエディタを http://127.0.0.1 で開き、API が http://localhost のみだと、ブラウザのオリジンが異なる扱いになり通信がブロックされることがあります。開けないときは、サイトも LM Studio も 同じホスト表記（どちらも 127.0.0.1 またはどちらも localhost）にそろえるか、LM Studio の CORS / サーバー設定を確認してください。

開発マイルストーン

  • 開発期間: 約6日間（集中開発フェーズ）
  • コンセプト: ボイラープレートレスな AI コード実行エコシステム
  • 主要技術: Local LLM（LM Studio）, JavaScript（Async Runtime）, Canvas API

実装済み主要機能

1. AI Interaction & Compilation

  • LM Studio Integration: ローカル完結の LLM 対話。
  • Auto-Compiler: 自然言語を実行可能な JavaScript にコンパイル。

2. Robust Execution Engine

  • Runtime Control: new Function と非同期で実行・停止を制御。
  • Implicit Context: executionState 等を前提に、本質的なロジックだけを生成しやすく。

3. Interactive Ecosystem

  • Canvas System: 生成コードからグラフィックスを制御。
  • Input Detection: キーボード入力を生成コードへ同期。

4. Advanced Prompt Engineering

  • Behavioral Constraint: 冗長な解説を抑え、コード純度を高めるプロンプト。

技術的なこだわり

AI に「何を書かせるか」だけでなく、「最も書きやすい環境」を作ることに注力。実行コンテキストの設計でハルシネーションや構文エラーを抑える。
